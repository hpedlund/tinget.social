## SEO

### Shared metadata — `lib/metadata.ts`

```ts
pageMetadata({ title?, description, path }): Metadata
// → { title, description, alternates: { canonical: path },
//     openGraph: { type: "website", locale: "sv_SE", siteName: SITE_NAME, url: path, title, description } }
```

Next.js replaces (not merges) a parent's `openGraph` in a child, so every page builds its full Open Graph block through this helper; otherwise a shared member page would show the start page's title. `path` always has the trailing slash used by the export (`/ledamoter/{id}/`). The ranking's canonical is `/`, so `/?parti=S` and other filter states consolidate to it.

Root `app/layout.tsx`: `metadataBase: new URL(SITE_URL)` and the same Open Graph defaults for pages without their own (404).

## Accessibility (WCAG 2.1 AA)

- **Automated**: axe-core (WCAG 2.0/2.1 A + AA tags) via Playwright against the static export: start page (default and a filtered state), a ranked member, a below-threshold member, `/partier/`, `/sa-raknar-vi/`, 404 — light and dark, 1280 px and 390 px.
- **Manual**: keyboard-only walk of every page type (skip link, focus visibility, order, filter controls, no traps), 200 % zoom / 320 px reflow, `prefers-reduced-motion`, page titles and `lang`.
- **Screen reader**: not available in the review environment; the review lists what to check with NVDA/VoiceOver before announcing.
- Violations at levels A/AA are fixed in this task.

## Security

Whole-repository review (code, pipeline, workflows, dependencies, headers GitHub Pages can and cannot send), written to `docs/reviews/TASK-012-security.md`. Critical/high findings are fixed here.

## Figure spot-check

`scripts/spot-check.ts` (`npm run data:spot-check`): for a fixed, documented sample, fetch each member's rows for each riksmöte from Riksdagen's `voteringlista` filtered by member (`iid`) — a different endpoint from the one the pipeline uses — tally `Ja`/`Nej`/`Avstår`/`Frånvarande` and compare with `data/members/{id}.json` → `byRiksmote`. Prints a table and exits 1 on any mismatch. Read-only; uses the existing throttled client in `lib/riksdagen/client.ts`.

Sample (chosen to cover the tricky rules): highest and lowest ranked for the full term, a member who switched party, a politisk vilde, a substitute below the threshold, a member who left during the term, and the largest party's median member. Results and the riksdagen.se links for a manual look are recorded in `docs/reviews/TASK-012-figures.md`.
